# Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `fvo-admin`, a port of Talk2Me's admin (Basecoat look, server-rendered pages) that runs on forever-vo's own data. It has a library dashboard, a Lines page with their take and yours, NPC pages, voice pages, and the Blizzard clips behind each voice.

**Architecture:** The pack browser's data layer (`tools/browse/` on this branch) moves to `tools/admin/` and grows:
- **`library.py`** adds the lines forever-vo knows as text but has no audio for.
- **`people.py`** indexes NPCs and voices.
- **`blizzard.py`** reaches Blizzard's NPCSounds barks and picked clips through `tools.wowdata`.
- **`dashboard.py`** counts the library.

A FastAPI app renders HTML pages with helpers ported from `talk2me/pipeline/admin.py` (`render.py`).

**Tech Stack:** Python 3.12 (uv), FastAPI + uvicorn (dependency group `admin`), Basecoat CSS from the CDN Talk2Me uses, plain inline JS, pytest + FastAPI TestClient.

**Spec:** `docs/superpowers/specs/2026-10-18-admin-design.md`. Port source: `C:\Users\jacqu\Documents\talk2me\pipeline\admin.py` (`CSS`, `PLAYER_JS`, `play`, `badge`, `avatar`, `model_image`, `duration`, `Admin.page`, `table`, `row`, `quests_page`, `voices_page`, `npc`).

**Interfaces:**
- Consumes: `Line`, `merge`, `natural` (lines.py); `Texts`, `load_texts`, `annotate` (texts.py); `Catalog`, `Filters` (catalog.py).
- Produces:
  - In `lines.py`:
    - `def is_variant(line: Line) -> bool`: True when `line.variant`, after dropping a leading `male`/`female`, is not empty (`sex …`, `speaker …`, `narrator …`).
    - `def line_key(line: Line) -> str`: `line.id` with a trailing `:male`/`:female` removed. Two rows with the same key are one line.
    - `def voiced(line: Line) -> bool`: `bool(line.files) and not line.missing`.
  - In `library.py`, `def library_lines(pack_lines: list[Line], texts: Texts) -> list[Line]`. It returns `pack_lines` plus one **text-only row** for each known line with no pack row of the same `line_key`, sorted by `natural(id)` as `merge` sorts. The known lines are:
    - `texts.quests["<qid>-<event>"]`, giving id `q:<qid>:<event>`, kind = event, `quest_id` = qid, and speaker = `int(entry["npc"])` when that is numeric
    - `texts.gossip["<speaker>|<hash>"]`, giving id `g:<speaker>:<hash>`
    - `Texts.books[...]`: add `books` to `Texts` and to `load_texts`'s merged kinds. A book gives id `b:<hash>` with title `entry.get("title")`

    A text-only row has `files=[]`, `pack=""`, `voice=None`, `duration=None` and `text=entry["text"]`. Its `path` is the file its line would have (`Quests/<qid>-<event>.mp3`, `Gossip/<speaker>-<hash>.mp3` or `Books/<hash>-page.mp3`), so a comparison take pairs with it.
  - In `catalog.py`:
    - `Filters.status: str = ""`. The values: `"voiced"` (`voiced(line)`); `"text_only"` (not voiced and `text` set); `"audio_only"` (voiced and `text` None); `"no_text"` (`text` None); `"yours"` (`compare_path(line)` set).
    - `Filters.variants: bool = False`. False keeps only rows where `not is_variant(line)`.
    - `Catalog.count_lines(f: Filters) -> int`: the number of distinct `line_key`s among the matching rows.

```python
@dataclass
class Npc:
    key: int                    # speaker key; negative for game objects
    name: str | None
    sexes: str                  # "m", "f", "mf" or "" (pack `sexes`, else capture/bulk `sexes`/`sex`)
    display_id: int | None      # capture/bulk npcs[key]["displayID"]
    model_file_id: int | None   # capture/bulk npcs[key]["modelFileID"], else pack `models`
    is_object: bool             # key < 0 or npcs[key]["isObject"]
    zones: list[str]            # zones of its lines, most frequent first
    voices: Counter[str]        # voice -> voiced rows of this speaker (variants included)
    lines: int                  # distinct lines spoken (line_key), voiced or not

@dataclass
class VoiceInfo:
    name: str
    tuning: dict[str, Any] | None      # its own [tts.voices.<name>] row, fields that are set, or None
    defaults: dict[str, Any]           # [tts] exaggeration, cfg_weight, tempo, pitch, speed
    fallbacks: list[str]               # [voices.fallbacks] chain from this voice, e.g. ["felorc", "orc"]
    pick: list[int]                    # clip FileDataIDs of the pick in use, own or borrowed
    pick_build: str | None
    borrowed_from: str | None          # the voice whose pick is shown when it is not this one's
    pinned_speakers: list[str]         # [voices.speakers] keys pinned to this voice
    speakers: Counter[int]             # speaker -> voiced rows in this voice
    rows: int                          # voiced rows in this voice
```

  - `def npcs_of(lines: list[Line], texts: Texts, tables_by_pack: list[dict[str, Any]]) -> dict[int, Npc]`: one entry per speaker that appears on any row.
  - `def voice_info(name: str, config: Config, lines: list[Line]) -> VoiceInfo | None`: None when no row uses `name` and the config doesn't know it (no tuning, pick, fallback or pin).
  - `def voices_in_use(lines: list[Line]) -> Counter[str]`: voice → voiced rows.
  - The fallback chain is followed through `config.voices.fallbacks` until a voice repeats (cycle-safe). The pick is `config.voices.sources[name]`, else the first voice along the chain that has one (giving `borrowed_from`).

```python
@dataclass
class Count:
    label: str
    value: int
    query: str            # the /lines query string that lists exactly these lines, e.g. "kind=progress&status=text_only"

@dataclass
class Summary:
    totals: list[Count]               # quests known; lines known; voiced; text only; audio only; yours; NPCs speaking; voices in use; variant recordings
    by_kind: list[list[Count]]        # per kind in order accept, progress, complete, gossip, book: [known, voiced, text only, yours]
    by_level: list[list[Count]]       # brackets "1-10".."61-70", "unknown": [known, voiced, yours]

    has_classic: bool

def summary(catalog: Catalog, npc_count: int, voice_count: int) -> Summary
```

  - **Counts** are `catalog.count_lines` of a `Filters` built from the same fields that the `query` string encodes. That shared builder is what guarantees a link reproduces its number.
  - **Not filters:** "quests known" (distinct `quest_id`s), "NPCs speaking", "voices in use" and "variant recordings" (voiced variant rows) aren't line filters. Their `query` is the closest view: quests → `kind=accept`, NPCs → `/lines`, voices → `/voices`, variants → `variants=1`. They are exempt from the reproduce test.
  - **Level brackets** use `level_min`/`level_max`. "unknown" needs `Filters.level_unknown: bool` (add it in catalog.py: True matches `level is None`).
